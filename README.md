
# 🍣 Sushi-Project | Restoran Web Sitesi

---

Bu depo, modern ve şık bir restoranın çevrimiçi varlığını güçlendirmek amacıyla geliştirilmiş, kullanıcı dostu ve **responsive (duyarlı)** bir web sitesi projesidir. Proje; ziyaretçilere restoranın zengin menüsünü, iletişim kanallarını, müşteri yorumlarını ve özel teklifleri estetik bir arayüzle sunmayı hedefler.

## 🛠️ Kullanılan Teknolojiler

Bu projenin geliştirilmesinde aşağıdaki modern web teknolojileri ve kütüphaneler tercih edilmiştir:

- **HTML5:** Sayfanın iskeletini ve anlamsal yapısını oluşturmak için.
- **CSS3:** Özel stil tanımlamaları, modern görsel tasarımlar ve esnek yerleşimler için.
- **Bootstrap:** Hızlı, mobil uyumlu ve grid tabanlı responsive tasarım altyapısı için.
- **JavaScript (ES6+):** Sayfa içi dinamik etkileşimler ve kullanıcı deneyimini artırmak için.
